# Object Oriented Programming

- Rust doesn't have object persay, but it has enough things (enums, traits, structs, impl) in order to implement the good OOP design patterns.

- A struct inherently has encapsulation
- A trait inherently uses inheritance (kind of)
- NOTE: when using trait objects, Rust must use dynamic dispatching (runtime)
