# Patterns and Matching

```
match VALUE {
    PATTERN => EXPRESSION,
    PATTERN => EXPRESSION,
    PATTERN => EXPRESSION,
}
```

```
let PATTERN = EXPRESSION;
```

- Patterns are either refutable or irrefutable.
- Irrefutable means the pattern can match for any possible value.
- Refutable means the opposite of irrefutable.
